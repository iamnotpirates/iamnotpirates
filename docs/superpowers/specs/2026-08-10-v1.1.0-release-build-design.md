# Release v1.1.0 & Build Automation Design

## 1. Overview & Goal

This design specifies the release preparation and build automation for `IAmNotPirates` version `v1.1.0`.

The `v1.1.0` release introduces the Playwright Chromium Auto-Healing System, ensuring seamless zero-configuration execution for non-IT users on Windows machines.

## 2. Scope & Technical Changes

### 2.1 Version Bumping (`1.0.1` -> `1.1.0`)
- `pyproject.toml`: Update `version = "1.1.0"`.
- `src/ui.py`: Update CLI banner header to display `v1.1.0`.
- `README.md`: Update version badges and release documentation references to `v1.1.0`.

### 2.2 PyInstaller Spec Optimization (`IAmNotPirates.spec`)
- Configure `hiddenimports` to explicitly include `playwright`, `playwright.sync_api`, `playwright._impl._driver`, `src.playwright_manager`, `src.ffmpeg_manager`, `src.n_m3u8dl_manager`.
- Ensure driver assets (`node.exe` and `package/cli.js`) are collected cleanly for PyInstaller packaging.

### 2.3 Build Automation Script (`scripts/build_release.py`)
- Create an automated build script `scripts/build_release.py` that:
  1. Cleans up previous `build/` and `dist/` artifacts.
  2. Executes `pyinstaller IAmNotPirates.spec --noconfirm`.
  3. Verifies the generated executable `dist/IAmNotPirates.exe`.
  4. Prints build statistics (file size, SHA256 checksum, and output path).

## 3. Verification Plan

1. **Unit & Metadata Tests**:
   - Verify `pyproject.toml`, `ui.py`, and `README.md` report `1.1.0`.
   - Run existing test suite to confirm zero regressions.
2. **Build Execution Verification**:
   - Run `python scripts/build_release.py`.
   - Confirm `dist/IAmNotPirates.exe` is generated cleanly.
